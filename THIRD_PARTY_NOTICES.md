## EPLAN documentation content

All five documentation indexes are built on the user's machine; no documentation text is redistributed
with this bundle.

- `data/eplan2025.sqlite` — generated at setup time from the .NET XML documentation shipped with the
  locally installed EPLAN Platform 2025.0.3
  (`C:\Program Files\EPLAN\Platform\2025.0.3\Bin\Eplan.EplApi.*u.xml`).
- `data/eplan2025-guide.sqlite`, `data/eplan2026-help.sqlite`, `data/eplan2027-help.sqlite`,
  `data/eecpro-help.sqlite` — generated by `scripts/build-help-index.py`, which crawls the public EPLAN
  help site (<https://www.eplan.help>) once and stores the pages locally for offline search. The
  2026/2027 databases hold both the API reference and the platform user guide pages.
- The documentation content is © EPLAN GmbH. Crawling follows the site's `robots.txt` (HTML pages
  only, no `.php/.css/.js/.xml/.txt/.png/.jpg/.gif`), is rate-limited, is intended for the user's own
  offline consultation, and the resulting databases must not be redistributed.
- Page URLs recorded in the indexes point at the public EPLAN help site
  (`/en-us/Infoportal/Content/api/2025|2026|2027/`, `/en-us/Infoportal/Content/Plattform/2025|2026|2027/Content/htm/`,
  `/en-us/infoportal/content/eecpro/2026/Content/htm/`).
- The site's `sitemap.xml` files are excluded by `robots.txt`; they are downloaded manually once per
  version (cached under `_recon/sitemaps/`) purely to learn the page-name list, not redistributed, and
  every page they name is still fetched subject to the rules above.
